# Personal Bank App

Base de départ pour une application web personnelle de gestion bancaire.

## Objectif

Préparer un espace propre pour intégrer ensuite ton code existant sans toucher au site APAM déjà présent à la racine du dépôt.

## Stack prévue

- React
- TypeScript
- Vite

## Structure

```text
personal-bank-app/
├── public/
├── src/
│   ├── App.tsx
│   ├── main.tsx
│   └── styles.css
├── .gitignore
├── index.html
├── package.json
├── tsconfig.json
├── tsconfig.app.json
├── tsconfig.node.json
└── vite.config.ts
```

## Démarrage

Quand les dépendances seront installées :

```bash
npm install
npm run dev
```

## Prochaine étape

Tu peux maintenant m'envoyer le code que tu as déjà préparé, et je l'intégrerai dans cette base.
